# Week2-개선사항1: TRIAGE-1 초기 구축

## 문제
- 데모 수준을 넘어, 현장 입력값으로 중증도 분류 후 병원 추천까지 이어지는 최소 동작 제품이 필요했다.

## 프롬프트(요약)
- Flask 기반 웹앱으로 입력 폼, 중증도 판단, 병원 추천 API를 연결해 기본 작동 흐름을 완성하라.
- UI는 모바일 우선으로 구성하라.

## 결과
- 서버: 기본 라우트와 추천 API 골격 구현.
- 화면: 입력 폼과 결과 렌더링 구조 생성.
- 문서: 설치/실행 기반 README 초안 형성.

## AI 시행착오 흔적
- 1차 프롬프트는 기능 나열형이라 구현 우선순위가 흔들림.
- 2차부터 입력-판단-추천-표시의 4단계 파이프라인으로 프롬프트를 재구성해 안정적으로 코드가 생성됨.
- 단순 "기능 추가"보다 "요청-응답 계약"(입력/출력 스키마)을 먼저 고정하는 방식이 효과적이었음.
