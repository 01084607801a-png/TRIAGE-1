# Week2-개선사항3: API 키 보안 전환

## 문제
- 문서/코드 경로에 키 노출 위험이 존재했고, 운영 시 키 혼용 가능성이 있었다.

## 프롬프트(요약)
- 키를 코드와 문서에서 제거하고 환경변수 기반으로 전환하라.
- README에는 실제 값 대신 설정 방법만 남겨라.

## 결과
- 키 하드코딩 제거.
- .env 및 환경변수 로딩 패턴 적용.
- 문서 보안 문구 정리 및 노출 가능 값 제거.

## AI 시행착오 흔적
- 1차 수정에서 문서의 예시 키 문자열 일부가 잔존.
- 2차 프롬프트에서 "문서/코드/샘플 문자열 전체 검색"을 요구해 누락 지점을 제거.
- 보안 수정 시 기능 회귀를 막기 위해 API 실패 메시지 경로도 함께 점검함.
