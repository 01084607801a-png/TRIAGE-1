# Week2-개선사항2: README 시연 증적 정리

## 문제
- GitHub에서 프로젝트 상태를 즉시 파악하기 어렵고, 실행 화면 증거가 부족했다.

## 프롬프트(요약)
- README에 스크린샷 섹션을 추가하고 이미지 경로를 GitHub 렌더링 기준으로 수정하라.
- 외부 사용자가 설치/실행 단계를 빠르게 따라올 수 있게 정리하라.

## 결과
- 실행 화면 이미지 삽입 완료.
- 경로 불일치 수정으로 GitHub 표시 안정화.
- README 내 구조(설치/실행/기능/개선사항) 가독성 향상.

## AI 시행착오 흔적
- 최초 이미지 경로가 로컬 기준이라 렌더링 실패.
- 프롬프트를 "상대경로 + 저장소 루트 기준"으로 명시한 뒤 해결.
- 파일명/폴더명 변경 시 README 링크도 동시 수정하도록 체크리스트를 추가해 재발 방지.
