# Week4-개선사항6: 빈 결과 안내 개선 + 데스크톱 실행기 추가

## 문제
- 일부 테스트에서 추천 병원이 화면에 비어 보일 때 사용자 입장에서 "앱이 멈췄다"고 느껴졌다.
- 브라우저 기반이 아닌, Run으로 바로 실행되는 소프트웨어 형태 테스트 요구가 있었다.

## 프롬프트(요약)
- 추천 결과가 없을 때 명확한 안내 문구를 UI에 보여줘라.
- 웹 페이지를 직접 열지 않아도 실행 가능한 데스크톱 실행기를 추가하라.

## 결과
- `static/script.js`에 빈 결과 상태 처리 추가:
  - `matched`가 비어 있으면 "추천 가능한 병원이 없습니다"와 재시도 가이드를 표시.
- `desktop_app.py` 추가:
  - Python/Tkinter 기반 네이티브 창에서 환자 입력 후 추천 실행 가능.
  - 내부적으로 Flask 서버를 자동 실행/종료해 사용자가 브라우저를 직접 열지 않아도 됨.

## AI 시행착오 흔적
- 초기에는 pywebview 방식으로 데스크톱 창을 열려고 했으나, 현재 환경에서 의존성 빌드 실패 발생.
- 프롬프트를 "외부 의존성 최소화"로 바꾸고 표준 라이브러리(Tkinter) 기반으로 전환해 안정적으로 해결.
- 백엔드가 정상 응답 중인데 프런트 표시가 빈 화면처럼 보이는 문제를 분리해 UI 처리로 보완.

## 사용 방법
- 데스크톱 모드 실행:
  - `python desktop_app.py`
- 웹 모드 실행:
  - `python app.py` 후 `http://127.0.0.1:5000`
