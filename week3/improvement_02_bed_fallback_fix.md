# Week3-개선사항2: 병상 고정값 fallback 제거

## 문제
- 상태 API 실패 시 병상 수가 고정값처럼 표시되어 신뢰성 이슈가 발생했다.

## 프롬프트(요약)
- 예외 상황에서 하드코딩 병상값을 반환하지 말고 None 처리로 변경하라.
- UI/응답에서 정보 없음이 분명히 보이도록 하라.

## 결과
- 가짜 병상 수 노출 제거.
- API 실패 시 정보 없음 처리로 데이터 신뢰성 개선.

## AI 시행착오 흔적
- 1차 수정은 일부 경로에서 기존 값이 남아 완전 제거 실패.
- 2차 프롬프트에 "예외/fallback/기본값 경로 전체 검색"을 포함해 누락 제거.
- 로그 태그를 추가해 실제 API 오류와 데이터 없음 상태를 구분 가능하게 함.
