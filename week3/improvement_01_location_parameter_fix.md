# Week3-개선사항1: 위치 파라미터 미반영 버그 수정

## 문제
- 사용자 좌표를 바꿔도 추천 병원이 거의 동일하게 나오는 문제가 있었다.

## 프롬프트(요약)
- 병원 조회 API 호출에 위도/경도/반경 파라미터를 명시적으로 포함하라.
- 페이지 단위 조회를 확장해 위치별 후보가 충분히 수집되도록 하라.

## 결과
- 위치 기반 병원 추천 정상화.
- 좌표 변경 시 추천 목록이 지역에 맞춰 달라짐.

## AI 시행착오 흔적
- 1차 프롬프트는 함수 내부 수정 지점이 모호해 누락 발생.
- 2차에서 "fetch 함수의 params dict에 필드명까지 고정"하도록 구체화해 해결.
- 테스트 프롬프트를 광주/서울/부산 3좌표로 명시해 회귀를 방지.
